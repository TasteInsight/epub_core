## 0.2.0

Initial release.

- Parse EPUB 2/3 containers, multiple renditions, OPF metadata, manifests and reading order.
- Read EPUB 3 navigation, EPUB 2 NCX, covers, fallback resources and presentation settings.
- Parse SMIL media overlays with text references, audio clips and clock values.
- Provide XML, HTML and CSS resource parsers, plus source documents and raw bytes.
- Deobfuscate IDPF/Adobe fonts and expose encryption declarations for application decoders.
- Read and cache resources on demand, with archive checks and configurable parsing limits.
- Return read-only publication models and diagnostics with resource paths and XML error locations.
- Support Dart VM, Flutter and Web.
